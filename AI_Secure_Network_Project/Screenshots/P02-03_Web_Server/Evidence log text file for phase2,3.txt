ISSUE FOUND & FIXED:
  Kali curl timed out (~134 s) although ping worked.
  Cause: Ubuntu host firewall (UFW) was active and silently dropping port 80.
  Fix: Allowed HTTP with "sudo ufw allow 80/tcp".
  Learning: A timeout (no reply) indicates a firewall DROP;
            "Connection refused" would mean the service is not running.
