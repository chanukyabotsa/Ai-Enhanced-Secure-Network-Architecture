Design: Trained PyTorch MLP exported to JSON (weights + scaler) and run
with NumPy on the Ubuntu server, next to Suricata (no PyTorch install needed).
Equivalence check (Colab, 20,000 real flows): max probability difference
0.000002, same decision 100.0%.

Script: ids_ai.py
  - reads Suricata eve.json flow events for the server segment
  - maps them to the 6 training features
  - AI P(attack) (real model output), threshold 0.4
  - correlates with Suricata alerts (same flow_id)
  - verdict: BOTH / SURICATA ONLY / AI ONLY / CLEAN
  - recommends investigation/block only (human-in-the-loop)
